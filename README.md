# Maya Math Intervention Coach

A parent-facing, low-visual-load teaching coach for mental addition and subtraction.

The child is **not** meant to sit on the website. The parent uses the site to choose one mathematical idea, set up physical manipulatives, ask one question, report what happened, and receive the next teaching intervention.

## Teaching design

The app follows this loop:

1. **Teach one idea** — one goal, one manipulative setup, one short script.
2. **Ask one question** — no timer and no screen-based child drill.
3. **Parent reports what happened** — correct / incorrect / different route / not confident enough to start.
4. **Diagnose before reteaching** — the app asks the parent to probe prerequisites one at a time.
5. **Route appropriately** — move up, stay at the same mathematical level, move down in representation, reduce working-memory load, or accept a different valid strategy.
6. **Generate more questions** — question banks are generated by rule at multiple difficulty levels, so the parent can request easier, similar, or harder examples.

## Strategy map

### Core prerequisites
- **Finish the Friendly Number** — complements to 10 and 100.
- **Break It** — decompose numbers into place-value parts and other equivalent decompositions.

### Singapore Primary Mathematics 2B Unit 6 progression represented in the app
- **Split & Hop — Addition** — add tens, then ones, leaving intermediate totals visible.
- **Split & Hop — Subtraction** — subtract tens, then ones, leaving intermediate totals visible.
- **Almost 100 — Addition** — +99 / +98 via +100 followed by compensation.
- **Almost 100 — Subtraction** — −99 / −98 via −100 followed by giving back the excess removed.

### Extension
- **Move Some Over** — redistribute between addends while preserving the total, e.g. 182 + 139 → 200 + 121.
- **Choose the Move** — mixed transfer practice where the child notices the number structure and chooses a valid route.

`Move Some Over` is included as an extension requested for this intervention program; it is not claimed here as a strategy explicitly diagrammed in the uploaded Primary Mathematics 2B workbook.

## Important pedagogical rules

- **Low visual load:** one decision at a time; no child dashboard.
- **Concrete → visible trail → symbolic → mental:** do not remove a representation merely because the arithmetic is age-appropriate.
- **Move down in representation, not automatically in mathematics:** if the child understands 246 + 98 but loses the intermediate total, keep the same problem and externalize the memory burden.
- **Valid alternative methods count:** do not mark a mathematically valid route wrong because it differs from the target strategy.
- **No speed requirement while a strategy is being built.**
- **Confidence is diagnostic information:** if the child will not start, reduce the performance demand to one first move rather than forcing the whole calculation.
- **Efficiency comes after validity, understanding, and fluency.**

## Manipulatives

Useful materials include:

- base-ten blocks / golden beads
- bead bars
- counters
- place-value cards
- two trays or mats for redistribution
- a hand-drawn open number line
- small paper cards for keeping intermediate totals visible

## Data

Progress is stored only in the browser's `localStorage`. No account or backend is required in this version.

## Files

- `index.html` — app shell
- `styles.css` — low-load parent-facing visual system
- `app.js` — strategy content, question generators, diagnostic decision tree, interventions, and local progress tracking
